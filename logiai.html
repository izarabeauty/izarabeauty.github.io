🤖 LogiAI — version base de connaissances (MVP)
LogiAI est une version MVP basée sur une base de connaissances structurée (métiers, glossaire, entreprises du site), pas un modèle de langage connecté en direct. Il ne fabrique jamais d'entreprise, d'offre d'emploi, de salaire ou de réglementation, et il t'oriente vers les sources officielles quand c'est pertinent. L'architecture est prête pour brancher un vrai modèle IA via une API backend sécurisée dans une version future.
